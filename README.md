# 🐶 PetShower

O **PetShower** é um projeto desenvolvido com o objetivo de aprofundar meus conhecimentos em desenvolvimento FullStack, utilizando principalmente:

* **Java + Spring Boot** no backend
* **Angular** no frontend

A ideia do projeto não é apenas construir um sistema funcional, mas também servir como um ambiente de estudos prático, onde posso experimentar arquiteturas, padrões de projeto, integração entre aplicações e boas práticas utilizadas no mercado.

---

# Objetivos do Projeto

Este projeto está sendo utilizado para aprender e praticar:

## Backend

* Construção de APIs REST com Spring Boot
* Estruturação de projetos Java
* DTOs e validações
* Tratamento de exceções
* Integração com banco de dados
* Arquitetura em camadas
* Boas práticas de organização

## Frontend

* Desenvolvimento de interfaces com Angular
* Componentização
* Consumo de APIs REST
* Organização de aplicações frontend
* Angular Material
* Estruturação de páginas e componentes reutilizáveis

---

# Sobre o Projeto

O PetShower simula um sistema de gerenciamento para pet shops, contendo funcionalidades relacionadas ao controle de pets, clientes e serviços.

O projeto está sendo desenvolvido de forma incremental, conforme novos conhecimentos são adquiridos durante os estudos.

Mais do que um projeto finalizado, o objetivo é transformar o PetShower em um espaço contínuo de aprendizado e evolução como desenvolvedora.
